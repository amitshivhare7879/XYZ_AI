# 01. Student Portal — XYZ AI

The **Student Portal** is the dedicated student web application for checking attendance, reviewing weekly schedules, managing homework assignments, and interacting with the **Friendly & Encouraging Academic AI Assistant** through chat, voice, and 3D avatar animations.

## Key Features
- **Student Dashboard**: Live attendance stats (83/91 days, 91.2%), class ranking (Top 5%), and timetable period tracker.
- **Academic AI Companion**: Tone-tailored for students — motivating, supportive, and age-appropriate.
- **Voice & 3D Avatar**: Real-time microphone speech recognition and animated avatar lip sync.
- **11 Languages**: Toggle between English, Hindi, Tamil, Telugu, Marathi, Bengali, Gujarati, Punjabi, Kannada, Malayalam, and Urdu.
- **Counselor Escalation**: One-click request for academic advisor / counseling sessions.

## Running Locally
```bash
python -m http.server 3001 --directory 01_student_portal
```
Visit: [http://localhost:3001](http://localhost:3001)
